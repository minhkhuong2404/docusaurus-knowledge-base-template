# Building Microservices — Study Guide

> **Book:** *Building Microservices: Designing Fine-Grained Systems, 2nd Edition*  
> **Author:** Sam Newman | **Publisher:** O'Reilly Media, 2021

This guide provides a detailed, chapter-by-chapter breakdown of Sam Newman's *Building Microservices* (2nd Edition).

## Book Structure

| Part | Chapters | Focus |
|------|----------|-------|
| 🏗️ **Foundation** | 1–4 | What microservices are, modeling, splitting monoliths, communication styles |
| ⚙️ **Implementation** | 5–13 | Communication tech, workflow, build, deploy, test, observability, security, resiliency, scaling |
| 👥 **People** | 14–16 | User interfaces, org structures, evolutionary architecture |
